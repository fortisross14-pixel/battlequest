# BattleQuest: Through the Ages

A turn-based tactical battle simulator for tablet and phone. Re-fight history's great battles (Marathon, Cannae, Agincourt, Waterloo…) with any general and any army: Napoleon leading Roman legions, Alexander leading Spanish tercios.

- Design: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)
- Agent prompts: [`docs/prompts/`](docs/prompts/)
- History briefs: [`docs/history/`](docs/history/)
- Reviews: [`docs/reviews/`](docs/reviews/)
- Agent prompts, in order: `01-kickoff` → `02-review-1-fixes` → `04-campaign-timeline` → `03-controls-and-motion`; `05-history-research` runs in parallel with a separate history agent
